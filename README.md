# Covid-19 data Analysis & Cleaning(Python)
# Project Overview:
 This project focuses on cleaning, transforming, and analyzing a real-world COVID-19 patient dataset using Python. The dataset contained encoded categorical values, missing data indicators, and inconsistent formats which were standardized to make the data analysis and visualization ready.
The cleaned dataset can be used for exploratory analysis, statistical insights, and dashboard development in tools like Power BI.

# Tools & Technologies :
1. Python (Pandas, NumPy, Matplotlib)
2. Jupyter Notebook

# Data Cleaning Steps:
Converted sex codes (1 → Female, 2 → Male)
Cleaned boolean columns (1 → Yes, 2 → No)
Replaced missing data codes (97, 98, 99) with NaN
Cleaned COVID classification column:
     1–3 → COVID Positive 
     4+ → COVID Negative / Inconclusive
Created age groups for better analysis
Exported cleaned dataset as CSV for visualization

# Key Outcomes:
* Created a fully standardized and analysis-ready dataset
* Improved data readability and usability
